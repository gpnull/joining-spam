# joining-spam

## tải: 
- link: https://github.com/gpnull/joining-spam/releases
- launcher phải chạy ở chế độ cửa sổ mới chạy được tool, scale của màn hình phải là 100%
- lưu ý: tool đang chỉ áp dụng chính xác nhất cho server chanh city.

## chỉnh chế độ cửa sổ:
### cách 1:
- thử nhấn tổ hợp phím alt + enter
### cách 2:
- vào một server khác trong fivem, rồi nhấn esc mở menu cài đặt.
- vào settings -> display -> graphics hoặc advanced graphics.
- tùy chọn Screen Type hoặc Window Mode. chuyển từ Fullscreen sang Windowed hoặc Windowed Borderless.
- nói chung là mò thử, miễn khi nhấn alt + tab mà nó không mất màn hình game là được.
- lưu thay đổi.

## cách dùng tool:
- mở tool, để ý góc trên phải rồi làm theo 
- -> click chuột vào "Chanh City" (nằm dưới cái nút "Vào ngay!" màu đỏ) 
- -> click chuột vào nút "Vào ngay!" 
- -> đợi cho ra bảng thông báo kết nối thất bại 
- -> click chuột vào nút "ĐÓNG".
- xong bên trên là xong setup, nhấn nút PAGE UP để bắt đầu chạy / tạm dừng, nhấn nút PAGE DOWN để dừng và thoát.
